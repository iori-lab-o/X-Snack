# 検証ルール

## 概要
意図しないコードの混入やデプロイエラーを防ぐため、特定の重要なアクションを行う前には必ず規定の検証手順を踏む必要があります。

## 適用条件
- `git commit` を実行しようとする直前
- `wrangler deploy` や各種デプロイコマンドを実行しようとする直前

## 必須動作
上記のアクションを行う前には、例外なく以下のワークフローを呼び出し、すべてのチェックがパスすることを確認してください。

1. `[/verify-all]` : 静的解析、ユニットテスト、E2Eテストの実行
2. `[/deploy-check]` : デプロイ環境の最終確認

これらを実行し、エラーがないことを確認した後に初めて、実際のアクション（コミットやデプロイ）に進むことができます。
